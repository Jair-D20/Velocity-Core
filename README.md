Este archivo habla sobre lo necesario a conocer a saber al momento de usar a Velocity AI Core

- Velocity es una IA que funciona en base a la Integración con Claves API, en este caso con las APIS de Gemini, Groq y GPT
- Para usar a Velocity es necesario insertar una clave API de cualquiera de estos 3 provedores de IA.
- Velocity se puede usar a través del navegador o descargando la página web de forma local
- Velocity no depende de una cuenta para funcionar, solo de una clave API
- Velocity Core guarda la clave API en el mismo navegador, por lo cuál es recomendado tener cuidado en donde se usa y borrar la clave API en caso de usarlo en una PC o dispositivo público o compartido.
- El modelo de Velocity fue hecho y elaborado en código con IA gracias a Gemini, sin emabrgo las ideas y correciones de bugs, junto al diseño de este proyecto fueron añadidad por mí.

Velocity no busca lucrar con su funcionamiento, únicamente ser una IA útil en momentos necesarios.
